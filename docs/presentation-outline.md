# CivicFix - Project Presentation Outline

This outline can be used to generate a `.pptx` presentation using Google Slides or Microsoft PowerPoint.

## Slide 1: Title Slide
- **Title:** CivicFix
- **Subtitle:** Empowering Citizens. Streamlining City Administration.
- **Visual:** Isometric architecture diagram or screenshot of the app's map interface.

## Slide 2: The Problem
- **Bullet 1:** Citizens lack a transparent way to report civic issues (potholes, streetlights).
- **Bullet 2:** City administrators lack real-time data and SLA tracking to efficiently resolve issues.
- **Bullet 3:** Current systems are fragmented and difficult to use.

## Slide 3: The Solution - CivicFix
- **Bullet 1:** A unified platform for citizen reporting and administrative oversight.
- **Bullet 2:** **For Citizens:** Beautiful, mobile-first issue reporting with photo uploads and map pinning.
- **Bullet 3:** **For Admins:** Comprehensive command center with analytics and SLA tracking.

## Slide 4: Key Features
- **Visual:** Screenshots of the UI (Reporting Flow, Dashboard, Issue Details).
- **Bullet 1:** Interactive map and issue discovery.
- **Bullet 2:** Community upvoting to prioritize critical issues.
- **Bullet 3:** Automated SLA tracking and status updates.

## Slide 5: Technical Architecture
- **Visual:** `architecture-diagram.png`
- **Bullet 1:** **Frontend:** React 19, Vite, Tailwind CSS 4, shadcn/ui.
- **Bullet 2:** **Backend:** Node.js, Express 5.
- **Bullet 3:** **Database:** PostgreSQL with Drizzle ORM.
- **Bullet 4:** **Monorepo:** pnpm workspaces for shared Zod schemas and API clients.

## Slide 6: Current State vs. Future Roadmap
- **Current State:** High-fidelity frontend prototype with mock data.
- **Next Steps:**
  - Implement database schema and migrations.
  - Build REST API endpoints in the Express server.
  - Integrate user authentication.
