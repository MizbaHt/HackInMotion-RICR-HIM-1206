# ADDITIONAL REQUIREMENTS — CIVIC FEED + COMPLAINT CATEGORIES

Update the existing CivicFix frontend with the following features.

## 1. COMPLAINT CATEGORIES

Use these primary civic issue categories:

1. Roads & Potholes

   * Potholes
   * Damaged roads
   * Road cracks
   * Broken speed breakers

2. Streetlights & Electricity

   * Broken streetlights
   * Damaged electric poles
   * Exposed electrical infrastructure

3. Garbage & Sanitation

   * Overflowing garbage bins
   * Uncollected garbage
   * Illegal dumping
   * Dirty public areas

4. Water Supply

   * Water leakage
   * Broken pipelines
   * Water supply problems
   * Contaminated water

5. Drainage & Sewage

   * Blocked drains
   * Overflowing sewage
   * Waterlogging
   * Open drains

6. Traffic & Signals

   * Broken traffic signals
   * Damaged traffic signs
   * Unsafe crossings

7. Parks & Public Spaces

   * Damaged benches
   * Broken playground equipment
   * Poor park maintenance

8. Public Property

   * Damaged public toilets
   * Damaged bus shelters
   * Damaged public infrastructure

9. Trees & Environment

   * Fallen trees
   * Dangerous branches
   * Environmental issues

10. Construction & Encroachment

    * Illegal construction
    * Road obstruction
    * Public-space encroachment

11. Public Safety

    * Open manholes
    * Dangerous infrastructure
    * Other public safety hazards

12. Other

    * Issues that do not fit another category

Use attractive category cards with icons.

Do not display all subcategories at once.

When a citizen selects a category, optionally show relevant subcategories.

---

# 2. SCROLLABLE CIVIC COMMUNITY FEED

The home page MUST contain a large, vertically scrollable community feed below the hero section.

The feed should be one of the most important parts of the homepage.

The experience should feel like a modern community platform, but it must remain professional and civic-focused.

The user should be able to freely scroll through many civic issues reported by citizens.

Use the existing dummy issue data to populate the feed.

Create at least 30 realistic dummy posts.

---

# 6. VOTING INTERACTION

The primary interaction on each feed post should be:

### ▲ Support Issue

Do not call it simply "Like".

The meaning is:

" I agree this problem needs attention."

When clicked:

```text
128 citizens affected
```

becomes:

```text
129 citizens affected
```

Animate the vote counter.

Change button to:

```text
✓ Supported
```

Persist vote state using localStorage.

Prevent duplicate votes from the same mock citizen.

---

# 7. FEED FILTERING

When the user clicks:

### Roads

Only show Roads-related issues.

### Garbage

Only show Garbage & Sanitation issues.

### Water

Only show Water Supply issues.

### Nearby

Sort issues based on mock distance.

### Trending

Sort using a combination of:

* Vote count
* Recent activity
* Priority

### Most Supported

Sort by vote count.

### Recently Reported

Sort by report date.

Add a smooth animated transition when filtering.

Make the homepage feel like an endless civic feed.

Example:

```text
First load:

```

Do not make actual network requests.

# 11. DUPLICATE-AWARE FEED

If multiple issues are close to each other and have the same category, visually connect them.

Example:

```text
🔗 Similar reports

3 citizens reported a similar pothole
within 180m of this location.

[View Related Reports]
```

This reinforces the application's duplicate detection concept.

On mobile:

* One issue card per row
* Large image
* Easy-to-tap Support button
* Category chips horizontally scrollable
* Trending issues horizontally scrollable
* Nearby issues horizontally scrollable
* Bottom navigation remains fixed

Make the mobile feed feel natural and app-like.

# 14. IMPORTANT UX PRINCIPLE

The homepage should answer three questions immediately:

### "What problems are happening around me?"

→ Community feed + map

### "Which problems need attention?"

→ Votes + priority + trending

### "How can I contribute?"

→ Report Issue + Support Issue

The overall experience should feel like:

**A community-powered civic issue network, not a complaint form.**
