# Build a Premium Smart City Civic Issue Reporting Platform — FRONTEND ONLY

Build a complete, polished, production-quality **frontend-only React.js web application** called **CivicFix**.

### Tagline

**"Report it. Track it. Fix it."**

IMPORTANT:
This is **FRONTEND ONLY for now**.

Do NOT build a backend, database, authentication server, API server, or real image storage.

Use **realistic dummy/mock data** and local React state/localStorage wherever needed to make the UI feel fully functional.

The code must be structured cleanly so a real FastAPI/Django backend and PostgreSQL database can be connected later without rebuilding the frontend.
